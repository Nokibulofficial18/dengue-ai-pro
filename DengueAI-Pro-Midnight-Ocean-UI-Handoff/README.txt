DENGUEAI PRO — MIDNIGHT OCEAN UI HANDOFF

1) Extract this folder inside the root of your latest DengueAI Pro repository, e.g.:
   <project-root>/ui-reference/
2) Open the project in Antigravity.
3) Attach or visually show the file `ui-reference/midnight-ocean-reference.png` to Antigravity (image models need the actual visual, not only a filename).
4) Ask Antigravity to read:
   ui-reference/UI_DESIGN_SPEC.md
   ui-reference/ANTIGRAVITY_MASTER_PROMPT.md
5) Paste the master prompt to launch the UI rebuild.
6) When complete, compare the actual app at 1672x941 to the screenshot. Expect some differences because the PNG is a static concept and includes illustrative data/geometry.

The files in this ZIP are reference material and implementation instructions, NOT prebuilt frontend components.
